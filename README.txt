Platformer Foundation
Yerçekimi (Gravity): Karakter havadayken aşağı düşmeli.
Zıplama (Jumping): Değişken zıplama yüksekliği (tuşa ne kadar basarsan o kadar zıplama) veya mekaniğe uygun sabit zıplama.
Çarpışma (Collision): Karakterin platformların içinden geçmemesi, yere tam basması. 

Platformer → zıplama, yerçekimi, collision var
Puzzle → oyuncu mekaniği anlamazsa geçemez
